common-ui 문서

Next.js · React · 순수 HTML 에서 같은 방식으로 쓰는 대시보드 셸 웹 컴포넌트 라이브러리. 문서는 두 페이지이고, 이 파일은 그 둘로 보내는 목차다.

  • 사용 안내 — guide.html 설치와 셋업, 컴포넌트별 라이브 데모, 프로퍼티 · 이벤트 · 슬롯과 .ns-* 클래스 표
  • 버전 기록 — changelog.html 태그마다 무엇이 왜 바뀌었는지와 이주 코드. dist/ 가 바뀌었는지도 태그별로 적는다

두 페이지는 라이브 데모를 위해 옆의 dist/ 를 읽는다. 설치된 패키지 안에서는 이미 들어 있고, 저장소를 직접 클론했다면 npm run build 를 한 번 실행한다.
